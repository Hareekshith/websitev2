CYBERSECURITY // OCT 21–27, 2024

Cyber Security Awareness Month

Hackathon & Value Added Program (VAP) — Hands-on ethical hacking, pentesting, and device defense.

Oct 21 – Oct 27 VIT Chennai Campus
Back to Events

Program Overview

The ACM Student Chapter presented the Cyber Security Hackathon & Value Added Program (VAP) — a gateway to becoming an ethical hacking professional. The program equipped students with practical knowledge to safeguard digital systems, analyze security vulnerabilities, and prepare for top-tier infosec careers.

Key Hands-On Modules

  • Kali Linux & Docker Testbed: Setting up secure virtual sandboxes for ethical hacking experimentation.
  • System & Device Hardening: Securing operating systems, configuring enterprise firewalls, and detecting malware.
  • Offensive Security Fundamentals: Penetration testing, vulnerability analysis, password cracking, and traffic inspection with Wireshark.
  • Cloud Native Security: Hands-on defense architectures on AWS and cloud infrastructure.

Guest Keynote: Behind the Screens

Featuring an interactive session with distinguished ethical hackers and security researchers on real-world cyber crime investigations, threat modeling, and defensive engineering.
